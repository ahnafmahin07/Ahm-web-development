## Replacing the demo visuals
The current chat attachment set did not expose the four referenced JPG files to the file workspace, so this package includes four self-contained SVG visual placeholders to keep the site fully runnable.

If your four images are available locally, replace the SVG files (or change the image paths in `index.html`) with:
- 1000058425.jpg
- 1000058424.jpg
- 1000058421.jpg
- 1000058422.jpg

The existing image CSS already preserves aspect ratio and rounded presentation.

## Contact form
The form is frontend-only. JavaScript validates fields and displays a success message, but it does not claim to send email. Connect it to your backend or preferred email service for production.

## Social links
Facebook, Instagram, LinkedIn and GitHub are placeholders (`#`) because actual profile URLs were not provided.
